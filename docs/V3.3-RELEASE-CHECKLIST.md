## Warning Scope

The WARN is not represented as a hardware PASS. The host gate cannot validate RF discovery, association under real AP conditions, Pager Portal/theme rendering, button delivery, LED/haptic/audio timing, alert event delivery, or eMMC behavior on the physical device.

The release notes expose this limitation and list the physical checks required for follow-up. Rollback criteria are documented. No automated or source-level gate is failing.

## Required GitHub Sequence

1. Push the reviewed release branch.
2. Require the `Quality` workflow to pass on the pull request.
3. Merge without rewriting unrelated default-branch history.
4. Create one annotated `v3.3.0` tag on the reviewed main commit.
5. Push the tag; the `Release` workflow rebuilds, re-runs the gate, and publishes checksummed assets.
6. Verify the GitHub release URL, asset checksums, workflow result, and tag target.

An existing tag or release is a hard stop. Published tags/assets are immutable; corrections require a new version.
